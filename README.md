# 鏡の啓示 PWA v0.1.1 プロトタイプ

## 実装済み
- スタート画面「鏡の啓示」
- 羊皮紙調カードバック
- 「一枚、ひらく」
- 49枚から均等抽選
- 49枚すべてのタイトル／メッセージデータ
- 表面 → タップで言葉面へ反転
- 「もう一枚引く」
- 7母層の配色
- 7母紋の透かし
- オフライン用Service Worker
- PWA manifest
- iPhone縦画面向けレスポンシブ設計

## 現時点の仮要素
- 本番風の切り絵表面画像は「水底で息を継ぐ者」の1枚のみ。
- 他48枚は母層カラー＋母紋＋簡易シルエットの仮表示。
- 49枚の本番画像完成後、assets/cards/へ順次差し替える設計。

## PCで確認
このフォルダでターミナルを開き、例：

    python -m http.server 8080

その後ブラウザで `http://localhost:8080` を開く。

## iPhoneでPWAとしてホーム画面に追加するには
iPhoneのホーム画面PWAとして安定利用するにはHTTPSで配信する必要があります。
次工程で無料の静的ホスティング等へ置けば、Safariから「ホーム画面に追加」で使用できます。

※ v0.1はまず画面サイズ、反転、文字量、体験の確認を目的にしています。
